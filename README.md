# Pure PHP MVC

A project based on the MVC pattern, featuring a simple and lightweight implementation of selected functionalities in pure PHP. The project was created without using external packages or libraries to demonstrate fundamental solutions.

**Note!**  
This project is provided solely for educational and inspirational purposes. It has not been tested for security, performance, or stability. It should not be used in production environments or for hosting real websites.

---

## Features

The project implements, among others:

- Routing and dynamic routing
- Database connection using PDO
- Lightweight ORM for database operations
- Error handling and logging
- HTTP handling: request, response, JSON response
- Session management
- View rendering with or without a template engine
- CSRF Token

---

## Warning
Due to the lack of testing, security audits, and optimization, **I do not recommend using this project for production deployments**. Doing so could pose serious security and stability risks for your application.
